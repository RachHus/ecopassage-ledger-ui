# 생태통로 관리대장 — 입력 UI (검토용)

「생태통로 관리대장」 표준 테이블 설계안을 **화면에서 직접 눌러 보며 검토**하기 위한 정적 페이지입니다.
조사야장(종이 서식)과는 별개의 산출물이며, 향후 웹 시스템으로 그대로 이식할 수 있도록
화면 · 검증 규칙 · 매칭 API를 분리해 두었습니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 관리대장 게시판 + 작성 화면(시설정보 · 모니터링 2개 탭) |
| `field-form.html` | 개선 조사야장 서식 (A4 4쪽, 인쇄용) |

## 무엇을 확인할 수 있나

**1. 지도에서 클릭 → 도로속성 자동 채움**
지도를 클릭하면 그 지점의 좌표가 입력되고 곧바로 도로가 조회됩니다.
좌표를 직접 타이핑해도 되고, 조회 결과는 도로등급 · 노선번호 · 도로명 · 왕복차로수로 자동 반영됩니다.
도로가 없는 지점은 수동입력으로 전환되며, 어느 경로로 입력했는지가
`ROAD_ATRB_SRC_SE_CD`(RSLK 자동 / RSMN 수동)에 함께 저장됩니다.

지도는 **배경지도(OpenStreetMap) 위에 표준노드링크 도로망을 겹쳐** 그립니다.
배경지도가 표준 XYZ 타일(Web Mercator, EPSG:3857) 기준이라 지도 내부 좌표도 여기에 맞추고,
EPSG:5186 으로 저장된 도로망은 타일을 읽을 때 한 번만 투영해 캐시합니다.

배경지도는 외부 타일 서버를 쓰므로, 인터넷이 막힌 내부망에서는 우측 상단 선택상자에서
**‘배경 없음’**으로 바꾸면 도로망만으로도 그대로 동작합니다.
다른 배경(예: VWorld)으로 바꾸려면 `index.html` 의 `BASEMAPS` 상수에서 URL 한 줄만 교체하면 됩니다.

- **도로등급별 색·굵기** — 고속국도(굵은 빨강)부터 시·군도(얇은 회색)까지 위계가 한눈에 보입니다
- **도로 위에 올리면** 도로명 · 등급 · 노선번호 · 왕복차로수 · 제한속도 · 링크ID · 기준일자 표시
- **드래그로 이동 · 휠로 확대/축소**, 선택 좌표에는 탐색 반경 원이 함께 그려집니다
- 지도 아래 **반경 내 도로 목록**에서 행에 마우스를 올리면 지도의 해당 도로가 강조됩니다
- 확정한 도로는 지도에서 초록색으로 굵게 표시됩니다
- [도로 자동조회]를 누르면 결과를 기다리지 않고 **즉시 그 좌표로 지도가 이동**합니다(조회 0건이어도)

배경지도와 도로망의 정합은 계산으로 확인했습니다 — 같은 좌표를 배경 타일 격자로 역산한 위치와
지도 변환으로 구한 위치가 **오차 0px**, 화면에 그려진 도로와 마커의 거리는 매칭 엔진이 계산한
거리와 **0.03m** 차이입니다(세종대로 기준 21.93m vs 21.96m).

**2. 시설정보 ↔ 모니터링 연계**
시설정보 탭에서 부대시설 설치 유·무를 바꾸면 모니터링 탭의 점검 선택지가 즉시 따라 바뀝니다.

| 시설정보 설치 | 설치의무 | 모니터링에서 고를 수 있는 값 |
|---|---|---|
| 유 | (무관) | 이상 없음 / 보수 필요 |
| 무 | 필수설치 (유도울타리 · 소형동물 유도울타리 · 방음벽 · 관리용 출입문 · 안내표지판) | **설치 필요** (자동 확정, 변경 불가) |
| 무 | 권고설치 (보행로 구분 차단벽 · 생태통로 내부 수로 · 수로 탈출시설 또는 덮개) | 설치 필요 / 설치 불필요 |

**3. 입지 기준 — 재지 않고 통과 여부만**
사면경사도·내부 토양깊이를 각도·cm로 재어 적지 않고 **통과 / 미통과 / 확인불가**만 고릅니다.
무엇을 보고 판단하는지가 화면 위쪽에 함께 표시됩니다(경사 1:2 = 2m 나아갈 때 1m보다 덜 올라가면 통과,
토양깊이 70cm 이상).

**4. 저장 → 최종 등록 → 게시판**
작성 화면에서 언제든 **저장**할 수 있고, 저장한 건은 게시판의 '작성 중' 목록에서 이어서 씁니다.
필수 항목과 오류 수준 규칙을 모두 통과해야 **최종 등록**으로 넘어가며, 등록을 마치면
관리대장 게시판으로 이동해 목록에서 조회됩니다. 등록완료 건을 고치면 다시 작성중으로 되돌아갑니다.

**5. 실제로 저장되는 형태**
게시판에서 등록완료 건을 누르면 상세가 열리고, 입력값이 표준 테이블 9개에 어떤 JSON으로
적재되는지 볼 수 있습니다. 기타사용물·밀렵도구를 '무'로 두면 유무 값이 아니라 `null`이
들어가는 것도 여기서 확인됩니다.

## 도로 자동조회 — 표준노드링크 전국 조회

국토교통부 표준노드링크(`link_new.gpkg`) **전국 자료를 그대로 씁니다.** 다만 원본은 575MB
(지오메트리만 266MB)라 웹으로 올릴 수 없으므로, 전국을 **10km 격자 타일**로 미리 잘라 두고
브라우저가 **좌표에 해당하는 타일 하나만** 내려받아 조회합니다. 별도 서버가 필요 없습니다.

| 항목 | 값 |
|---|---|
| 타일 | 1,173개 (도로 없는 격자는 만들지 않음) |
| 링크 구간 | 1,905,416개 |
| 용량 | 원본 135.5 MB → **gzip 31.3 MB** (타일당 평균 27KB · 최대 268KB) |
| 선형 단순화 | Douglas-Peucker 1m — 정점 1,467만 → 696만 (47%) |
| 조회 속도 | 최초 조회 타일당 수십 ms · 같은 지역 재조회 3ms (캐시) |

조회 반경 상한(500m)만큼 각 타일을 넓혀 담았기 때문에, 좌표가 타일 경계에 있어도
이웃 타일을 챙길 필요가 없습니다. 좌표변환(EPSG:5186)과 점-선분 최단거리 계산식은
서버 구현(`server/roadmatch.py`)과 같은 식을 씁니다.

**원본 대조** — 브라우저 조회 결과를 원본 gpkg 직접조회와 맞춰 본 값입니다(오차 1m 이내).

| 지점 | 원본 gpkg | 브라우저(타일) |
|---|---|---|
| 정부대전청사 | 청사로 25.07m | 청사로 24.69m |
| 광화문 | 세종대로 21.94m | 세종대로 21.96m |
| 서해안고속도로 | 서해안고속도로 0.01m | 서해안고속도로 0.08m |
| 서울시청 앞 | 세종대로 59.30m | 세종대로 58.84m |
| 지리산 자락 | 0건 | 0건 |

차이는 타일을 만들 때 적용한 1m 선형 단순화에서 옵니다. 매칭 결과(어느 도로인지)는 동일합니다.

### 타일 다시 만들기

표준노드링크 갱신본을 받으면 `server/make_tiles.py` 로 다시 만듭니다.

```bash
python server/make_tiles.py roadtiles
```

`server/roadmatch.py` 첫머리의 `GPKG` 상수가 원본 파일 경로를 가리킵니다.
전체 자료를 서버로 조회하는 참조 구현(`server/road_match_server.py`)도 그대로 두었습니다.

## 좌표계에 관한 주의

배포된 GeoPackage에는 좌표계가 `Undefined (GDAL 99999)`로 기록되어 있어 파일만으로는 확정할 수 없습니다.
좌표 범위와 실지점 대조로 **EPSG:5186 (Korea 2000 / 중부원점 2010)** 임을 확인했습니다.

- 서울시청 앞(37.5663, 126.9779) → 세종대로 59.3m
- 광화문(37.5720, 126.9769) → 세종대로 21.9m
- 정부대전청사(36.3600, 127.3845) → 청사로 25.1m
- 링크 정점 → 위경도 → 재매칭 왕복검증 4건 전부 오차 0.00m

표준노드링크 갱신본에서 좌표가 어긋나면 이 대조를 다시 해 보고, 필요하면
`server/roadmatch.py`의 투영 상수(`LAT0`, `LON0`, `FE`, `FN`)를 조정하십시오.

## 이 페이지가 다루지 않는 것

- 저장은 브라우저 안(localStorage)에만 됩니다. 실제 구현에서는 이 자리가 표준 테이블에 대한 저장 API가 됩니다.
- 찻길 사고 건수는 **로드킬 정보 연계 자리**만 만들어 두고 임의 값으로 시연합니다.
  연계 대상 시스템이 확정되면 이 부분을 조회 API 호출로 바꿉니다.
- 사진 첨부, 동식물 종 목록 자동완성(KTSN 연계)은 화면 구성만 두고 연동은 하지 않았습니다.
- 표준 테이블 정의서(컬럼 정의 · 공통코드 · 업무규칙 · 커버리지 검증) 본문은 별도 xlsx 산출물에 있습니다.

## 구성

```
index.html          입력 UI
field-form.html     개선 조사야장 서식 (인쇄용)
roadtiles/          표준노드링크 전국 타일 색인 (10km 격자 · gzip JSON)
server/
  roadmatch.py          매칭 엔진 — 좌표변환 · R-tree 후보추출 · 점-선분 최단거리
  road_match_server.py  HTTP API + UI 서빙
  make_tiles.py         roadtiles 재생성 스크립트
  README.md             API 규격 · PostGIS 이식 방법
```

의존성 없음 — 브라우저만 있으면 열립니다. 매칭 서버도 파이썬 표준 라이브러리만 사용합니다.

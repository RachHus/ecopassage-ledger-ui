# 생태통로 관리대장 — 입력 UI (검토용)

「생태통로 관리대장」 표준 테이블 설계안을 **화면에서 직접 눌러 보며 검토**하기 위한 정적 페이지입니다.
조사야장(종이 서식)과는 별개의 산출물이며, 향후 웹 시스템으로 그대로 이식할 수 있도록
화면 · 검증 규칙 · 매칭 API를 분리해 두었습니다.

| 페이지 | 내용 |
|---|---|
| `index.html` | 관리대장 게시판 + 작성 화면(시설정보 · 모니터링 2개 탭) |
| `field-form.html` | 개선 조사야장 서식 (A4 4쪽, 인쇄용) |

## 무엇을 확인할 수 있나

**1. 위경도 → 도로속성 자동 채움**
좌표를 넣고 [도로 자동조회]를 누르면 국토교통부 표준노드링크에서 해당 지점의 도로를 찾아
도로등급 · 노선번호 · 도로명 · 왕복차로수를 자동으로 채웁니다.
도로가 없는 지점은 수동입력으로 전환되며, 어느 경로로 입력했는지가
`ROAD_ATRB_SRC_SE_CD`(RSLK 자동 / RSMN 수동)에 함께 저장됩니다.

**2. 시설정보 ↔ 모니터링 연계**
시설정보 탭에서 부대시설 설치 유·무를 바꾸면 모니터링 탭의 점검 선택지가 즉시 따라 바뀝니다.

| 시설정보 설치 | 설치의무 | 모니터링에서 고를 수 있는 값 |
|---|---|---|
| 유 | (무관) | 이상 없음 / 보수 필요 |
| 무 | 필수설치 (유도울타리 · 소형동물 유도울타리 · 방음벽 · 관리용 출입문 · 안내표지판) | **설치 필요** (자동 확정, 변경 불가) |
| 무 | 권고설치 (보행로 구분 차단벽 · 생태통로 내부 수로 · 수로 탈출시설 또는 덮개) | 설치 필요 / 설치 불필요 |

**3. 입지 기준 — 재지 않고 통과 여부만**
사면경사도·내부 토양깊이를 각도·cm로 재어 적지 않고 **통과 / 미통과 / 확인불가**만 고릅니다.
무엇을 보고 판단하는지가 화면 위쪽에 함께 표시됩니다(경사 1:2 = 2m 나아갈 때 1m보다 덜 올라가면 통과,
토양깊이 70cm 이상).

**4. 저장 → 최종 등록 → 게시판**
작성 화면에서 언제든 **저장**할 수 있고, 저장한 건은 게시판의 '작성 중' 목록에서 이어서 씁니다.
필수 항목과 오류 수준 규칙을 모두 통과해야 **최종 등록**으로 넘어가며, 등록을 마치면
관리대장 게시판으로 이동해 목록에서 조회됩니다. 등록완료 건을 고치면 다시 작성중으로 되돌아갑니다.

**5. 실제로 저장되는 형태**
게시판에서 등록완료 건을 누르면 상세가 열리고, 입력값이 표준 테이블 9개에 어떤 JSON으로
적재되는지 볼 수 있습니다. 기타사용물·밀렵도구를 '무'로 두면 유무 값이 아니라 `null`이
들어가는 것도 여기서 확인됩니다.

## 도로 자동조회 — 두 가지 동작 모드

### 데모 모드 (기본값 · 서버 불필요)
표준노드링크 원본은 575MB라 배포할 수 없으므로, **데모 지점 주변만 잘라낸 표본**(`demo_links.json`, 423개 링크)을
페이지에 함께 두고 브라우저에서 같은 매칭 연산을 수행합니다. 화면의 데모 지점 단추로 바로 시험할 수 있습니다.

| 데모 지점 | 예상 결과 |
|---|---|
| 정부대전청사 | 청사로 · 특별·광역시도(104) · 왕복 4차로 |
| 광화문 | 세종대로 · 일반국도(103) · 노선 48 · 왕복 6차로 |
| 서해안고속도로 | 서해안고속도로 · 고속국도(101) · 노선 15 · 왕복 4차로 |
| 지리산 자락 | 반경 내 도로 없음 → 수동입력 전환 |

브라우저 계산값은 서버 계산값과 **0.02m 이내**로 일치합니다(표본 좌표를 10cm 단위로 반올림해 저장한 차이).

### 전체 자료 모드 (매칭 서버 실행)
표준노드링크 전체(155만 건)를 조회하려면 `server/` 의 매칭 서버를 띄웁니다. 외부 라이브러리는 필요 없습니다.

```bash
python server/road_match_server.py
```

띄운 뒤 <http://127.0.0.1:8765/> 로 접속하면 같은 화면이 열리고, 상태 표시줄이 자동으로
'데모 모드'에서 'API 연결됨'으로 바뀝니다. 자세한 내용은 [`server/README.md`](server/README.md).

> 매칭 서버는 `link_new.gpkg`(국토교통부 표준노드링크) 파일 경로를 `server/roadmatch.py` 첫머리의
> `GPKG` 상수에서 읽습니다. 파일 자체는 용량 때문에 저장소에 포함하지 않습니다.

## 좌표계에 관한 주의

배포된 GeoPackage에는 좌표계가 `Undefined (GDAL 99999)`로 기록되어 있어 파일만으로는 확정할 수 없습니다.
좌표 범위와 실지점 대조로 **EPSG:5186 (Korea 2000 / 중부원점 2010)** 임을 확인했습니다.

- 서울시청 앞(37.5663, 126.9779) → 세종대로 59.3m
- 광화문(37.5720, 126.9769) → 세종대로 21.9m
- 정부대전청사(36.3600, 127.3845) → 청사로 25.1m
- 링크 정점 → 위경도 → 재매칭 왕복검증 4건 전부 오차 0.00m

표준노드링크 갱신본에서 좌표가 어긋나면 이 대조를 다시 해 보고, 필요하면
`server/roadmatch.py`의 투영 상수(`LAT0`, `LON0`, `FE`, `FN`)를 조정하십시오.

## 이 페이지가 다루지 않는 것

- 저장은 브라우저 안(localStorage)에만 됩니다. 실제 구현에서는 이 자리가 표준 테이블에 대한 저장 API가 됩니다.
- 찻길 사고 건수는 **로드킬 정보 연계 자리**만 만들어 두고 임의 값으로 시연합니다.
  연계 대상 시스템이 확정되면 이 부분을 조회 API 호출로 바꿉니다.
- 사진 첨부, 동식물 종 목록 자동완성(KTSN 연계)은 화면 구성만 두고 연동은 하지 않았습니다.
- 표준 테이블 정의서(컬럼 정의 · 공통코드 · 업무규칙 · 커버리지 검증) 본문은 별도 xlsx 산출물에 있습니다.

## 구성

```
index.html          입력 UI
field-form.html     개선 조사야장 서식 (인쇄용)
demo_links.json     데모용 표준노드링크 표본 (EPSG:5186 평면좌표)
server/
  roadmatch.py          매칭 엔진 — 좌표변환 · R-tree 후보추출 · 점-선분 최단거리
  road_match_server.py  HTTP API + UI 서빙
  make_demo.py          demo_links.json 재생성 스크립트
  README.md             API 규격 · PostGIS 이식 방법
```

의존성 없음 — 브라우저만 있으면 열립니다. 매칭 서버도 파이썬 표준 라이브러리만 사용합니다.
